
# Responsive Personal Portfolio Website

A professional, responsive portfolio website built as a web development
internship project.

## Features

- Home and introduction section
- About section
- Technical skills section
- Featured projects
- Education and experience timeline
- Contact form with JavaScript validation
- Responsive mobile navigation
- Mobile, tablet and desktop layouts
- Dynamic copyright year

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Project Structure

personal-portfolio/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download or clone the project.
2. Open the folder in VS Code.
3. Open index.html in a browser.
4. Alternatively, use the Live Server extension.

## Customization

- Update your name and introduction in index.html.
- Add your actual GitHub and LinkedIn profile URLs.
- Update project descriptions and repository links.
- Change the colors in the CSS :root section.
- Connect the contact form to a backend or email service.

## Deployment

You can deploy this static website using GitHub Pages, Netlify or Vercel.
